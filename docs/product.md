# 产品定位

- 产品：chmod 权限计算器工具站
- 域名：`chmodtool.com`
- 目标用户：开发者和运维人员
- 核心场景：在符号权限与数字权限之间转换并核对 chmod 设置
- 流量与变现：自然搜索流量，后续接入广告
- 当前语言：英文 `en`

## 最小上线范围

- 首页即工具页，页面 `<title>` 与 `<h1>` 均为 `chmod calculator`
- 纯前端运行，不保存用户输入
- 每页支持独立 title、description、canonical 和 Open Graph
- 提供 `sitemap.xml` 与 `robots.txt`
- 保留 Google Analytics 和 Search Console 的构建时配置位
- 保留一个不加载广告脚本的空广告位
